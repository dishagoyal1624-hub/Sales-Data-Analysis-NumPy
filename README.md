# Sales Data Analysis using NumPy

## Project Overview

This project focuses on analyzing monthly sales data of different
products using Python and NumPy.

The analysis explores sales performance, monthly trends, product-wise
performance, sales growth, and product contribution to overall sales.

## Dataset

The dataset contains sales information for five products across
12 months, from January to December.

### Products

- Laptop
- Smartphone
- Headphones
- Keyboard
- Mouse

## Objectives

- Analyze individual sales performance
- Calculate total and average sales
- Identify highest and lowest sales
- Perform monthly sales analysis
- Perform product-wise sales analysis
- Analyze month-over-month sales growth
- Analyze product sales growth
- Calculate product contribution to total sales
- Identify top-performing products

## Analysis Performed

The project uses NumPy to perform:

- Array creation and manipulation
- Aggregation using `sum()`, `mean()`, `max()`, and `min()`
- Index-based analysis using `argmax()` and `argmin()`
- Monthly sales analysis
- Product-wise sales analysis
- Sales growth analysis
- Percentage contribution analysis

## Key Insights

The analysis identifies:

- Highest and lowest individual sales
- Highest and lowest performing months
- Highest and lowest performing products
- Largest month-over-month sales increase
- Product with the highest sales growth
- Product with the largest contribution to total sales

## Technologies Used

- Python
- NumPy
- Jupyter Notebook

## Conclusion

This project demonstrates how NumPy can be used to efficiently
analyze structured sales data and extract meaningful business
insights from numerical data.
